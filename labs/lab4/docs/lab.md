# Lab4 · Skills 与长期记忆

## 场景

客服队列里有 10 张工单。Agent 逐张处理，**每张工单都在一个新会话中进行**：新的 Agent、空的上下文，和真实的客服系统一样。工单之间唯一能保留下来的，是你写进 `memory/` 的内容。

公司有三份政策（退款、升级转人工、延误补偿），每份几千字，真正要用的规则只占一小部分。默认情况下 Agent 只能用 `read_policy` 读全文。

有些信息只有跨工单才用得上：
- 处理第 2 张工单时能查到一个系统问题：支付网关 PG-B 在超时重试时会再扣一次款，而且这笔扣款不关联订单，只出现在支付日志里。第 6、9 张工单是同样的问题，但客户描述得更含糊；
- 第 1 张工单的客户说明只接受短信联系，第 7 张是同一位客户；
- 第 3 张工单提交后的质检意见给出了一条规则，之后的所有工单都要遵守。

## 开始之前

```bash
uv sync
uv run python agent.py --task --reset-memory    # baseline
```

`--task` 结束时打印每张工单的结果：是否提交、步数、读了哪些政策、退款/补偿/渠道/工单号等是否符合政策，以及总的 token 用量。把 baseline 记进 `docs/record.md`。

对话模式中，`/next` 在新会话里处理下一张工单，`/state` 查看各工单的结果，不带 `/` 的输入会发给一个带着当前记忆的自由对话 Agent（可以用来问"你记得客户 C5001 的偏好吗"）。

做对比时每次都加 `--reset-memory`，从空记忆开始。

## 目标 1：让 Agent 支持 skill

**要实现**：
- 把三份政策写成 skill：`skills/<名字>/SKILL.md`，开头是 `name` 和 `description` 的 YAML frontmatter，正文写清楚操作步骤；
- 至少一个 skill 带资源文件（例如把补偿面额对照表放进 `references/`），正文里只说"面额见对照表"，体现**元数据 → 正文 → 资源**三级按需加载；
- 用 Strands 的 `AgentSkills` 插件接入（`from strands.vended_plugins.skills import AgentSkills`）；Agent 还需要一个能读取资源文件的工具；
- 完成 `/skills` 命令：列出可用的 skill，以及上一个会话加载了哪些。

**约束**：政策内容只能来自你写的 skill，不要把政策全文放进 system prompt（可以另做一个这样的对照模式）。

**验收**：处理退款工单时加载退款 skill；处理延误工单时加载补偿 skill 并读取对照表；不再整篇读取政策。

**观察**：system prompt 的长度；每张工单加载了哪些 skill；与"政策全文放进 prompt"的对照组比较 token 和结果。

**设计决策**：`description` 怎么写，才能让模型在对的时候加载对的 skill。

## 目标 2：长期记忆 pipeline（采集 → 抽取 → 治理 → 使用）

**要实现**：
- **采集**：在 `on_session_end` 中保存本次会话的轨迹（`session.trajectory`）；
- **抽取**：用模型从轨迹中抽取值得长期记住的内容，分为事实、偏好、经验教训，每条带来源工单、时间、置信度，保存为 Markdown；
- **治理**：
  - 去重：与已有记忆重复时合并，而不是追加；
  - 消歧：同一件事的说法冲突时，决定保留哪一条，旧的标注为被替代；
  - 遗忘：长期没用到、置信度低的记忆降权或删除；
  - 完成 `/memory`（查看记忆）和 `/forget <关键词>`（手动遗忘）命令；
- **使用**：在 `build_agent` 中检索与本工单相关的记忆，放进 system prompt，并记录注入了哪些条目。

**约束**：记忆必须从轨迹中抽取，不要依赖执行任务的 Agent 自己调用 "remember" 之类的工具（真实运行中，这种方式漏掉了最关键的那条事实，还写入了一条无用记录并在后续工单中被注入）。

**验收**：
- 第 6、9 张工单直接利用 PG-B 的事实，在支付日志中找到多扣的那一笔并退款；
- 第 7 张工单用短信回复客户；
- 第 3 张之后，回复的第一行都写明工单号。

**观察**：每个会话结束后写入了什么、合并了什么、替代了什么；每个会话开始时注入了哪些记忆、来自哪张工单；后 5 张工单的步数与前 5 张对比。

**设计决策**：什么值得记；检索时怎样让"好像被多扣了一笔钱"这种含糊的描述也能命中（提示：写入时就为每条记忆准备好触发词）；遗忘的规则。
